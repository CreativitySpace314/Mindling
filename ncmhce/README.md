# NCMHCE Clinical Lab

Interactive study app for NCMHCE preparation.

## Included
- 65 original practice questions
- 5 unfolding case studies with 3 stages each
- Quick Drill by domain
- 20-question timed simulator
- High-yield flashcards
- Automatic missed-question queue
- Confidence tracking, notes, and local mastery data
- Current exam and July 1, 2027+ blueprint views

## Source alignment
The interface is organized around NBCC's published NCMHCE blueprints and exam format. Practice questions are original and are not official NBCC items.

## Local data
Progress is stored in the browser with localStorage. No account or server is required.
